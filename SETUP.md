# Installation Guide — Mail Chess

## Installation Steps

1. Download the ZIP file.
2. Extract the ZIP file.
3. Run `setup.bat`.

### Installing Python (Windows)

You can install Python by running the following command in **PowerShell**:



> **Note:**  
> Make sure **Python 3.10 or newer** is installed before running `setup.bat`.


```powershell
winget install -e --id Python.Python.3.12
```
## Upon installation
Setup.bat creates the virtual environment along with other necessary files. Upon setup the application should start. After setup you can start the application running `desktop_start.bat` or “python app.py” from terminal inside the folder:
